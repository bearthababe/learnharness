# Council rubric for the linear-algebra tutor key

**Frozen after round 1** (incorporating all three round-1 reviewers' rubric changes). Score
each criterion 0–10 and give an overall score 0–10. The overall is not a plain average:
any blocker caps it at 6.

| # | Criterion | What a 10 looks like |
| --- | --- | --- |
| K1 | Subject truth | Every mathematical claim is correct and scoped, with the field (ℝ/ℂ) stated. Eigen data is complete and derived, not just listed. Numeric claims are machine-checked, and the key says exactly what the checker covers. |
| K2 | Source provenance | Each subject claim traces to an inspected passage (section/page) or an explicit derivation. Each teaching expectation traces to the policy file that actually states it. A citation that cannot be inspected is labeled as such, not used as support. |
| K3 | Evaluability | Two independent evaluators would reach the same outcome. Defines applicability, an omitted required action (a violation once due), judgments spanning several turns, insufficient evidence (unverified), and how expectation outcomes aggregate into the run verdict. |
| K4 | Valid variation | Equivalent answers, methods, routes, examples, orders and Socratic or expository teaching all pass. There is no exact-transcript oracle and no fixed probe route. |
| K5 | Teaching-policy fidelity | Judges each turn's purpose using the specific policy points: every step checked before building on it; motivated or unconditional basis; minimal-tree plan; predictions are distinct from checks; recall checks are allowed when nothing can be applied; probe bracketing; repair before continuing. Neither adds nor drops policy, and practice-only rules are not applied to teaching. |
| K6 | Learner-evidence honesty | A single miss is not a misconception; helped is not independent; visited is not understood. Planned simulator events that never get their chance are unexercised, not deviations; simulator deviation invalidates the run, not the tutor. |
| K7 | Calibration power | Every example is consistent with the key's own rules (an inconsistency is a blocker). Includes contextual episodes. Catches both false acceptance and false rejection, includes at least one subtle bad example for each core teaching expectation, and has an insufficient-evidence example. |
| K8 | Fit to the bounded run | Written turn and request arithmetic for one valid route. A stated minimum coverage for a complete run. Caps lead to incomplete, never pass; violations observed before a cap still stand. Required checks are never compressed away to fit. |
| K9 | Owner-approvability | Short and clear enough to approve in one sitting; tight scope; open questions explicit, each with a recommendation. |
| K10 | Independence and leakage | A self-contained learner brief. Key, facts and calibration are excluded from both tutor and simulator, and the enforcement the live adapter needs is stated. |

**Blockers:** any K1 error; an attribution the cited source does not support (paraphrase
drift alone is not a blocker); a calibration example inconsistent with the key.

## Comparison rounds

From round 2 you receive two versions, **A** and **B**, in random order. Score both on
every criterion, list what is better and worse in each, name any blockers, and vote
**promote A**, **promote B**, or **no difference**. Prefer the smaller, clearer version when
quality is equal. Do not ask for scope beyond the key's §1.
