# Executable learning stories use Cucumber

The owner-approved learning-journey verification contract requires readable
Gherkin executed by Cucumber alongside existing lower-level tests. A separate
homemade parser or exact tutor-transcript matching would obscure pending steps
and reject valid conversations. Extend the single permanent LearnHarness prover
with this additive lane, keeping workflow regression evidence distinct from
independently approved live tutor evaluation and human learning efficacy.
